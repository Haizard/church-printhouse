# **App Name**: Evergreen Sanctuary

## Core Features:

- Dynamic Blog System: A content management interface for church staff to create, categorize, and publish blog posts, which are then displayed in a visually appealing card format and individual detail pages for visitors.
- Searchable Sermon Library: Upload, categorize, and store audio and video sermon content, accessible by visitors through a search interface filterable by topic, speaker, or date.
- Interactive Events Calendar: An intuitive calendar displaying upcoming church activities, allowing visitors to view event details and add them to their personal calendars.
- Secure Contact Form: A user-friendly form for visitors to submit inquiries or messages to the church, ensuring reliable delivery to the appropriate administrators.
- Admin Content Management Dashboard: A secure area for authorized church personnel to manage all blog posts, sermon entries, event details, and other website content.
- AI Sermon Outline Assistant: A generative AI tool that suggests sermon outlines or points for discussion based on selected scripture passages or thematic keywords provided by an administrator.

## Style Guidelines:

- Primary color: Deep forest green (#264D2E) to convey growth and serenity, contrasting effectively with light backgrounds.
- Background color: A very light, desaturated creamy green (#F4F8F5) providing a calming and clean canvas.
- Accent color: Muted olive-green (#697E3C) to add an earthy touch and highlight interactive elements without being overtly vibrant.
- Headline font: 'Literata' (transitional serif) for an elegant, literary feel, appropriate for headings and titles. Body font: 'PT Sans' (humanist sans-serif) for clear readability and a modern, welcoming presence in longer text blocks.
- Simple, elegant line icons representing spiritual themes, community, and core functionalities (e.g., prayer, gathering, message).
- Clean, organized, and inviting layout with generous use of white space, ensuring content readability and intuitive navigation across all device sizes.
- Subtle and purposeful animations for page transitions, interactive elements like button hovers, and content loading, enhancing the user experience without distraction.
